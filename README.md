# Estudos e Atividades em Dart

Repositório destinado ao armazenamento e compartilhamento de atividades, exercícios e projetos desenvolvidos durante meus estudos de **Dart** na faculdade de Engenharia de Software.

O objetivo é documentar meu aprendizado, praticar os conceitos da linguagem e acompanhar minha evolução no desenvolvimento de aplicações.

## 🎯 Objetivos

- Aprender e praticar a linguagem Dart.
- Desenvolver a lógica de programação.
- Aplicar conceitos de Programação Orientada a Objetos (POO).
- Resolver exercícios e desafios propostos nas aulas.
- Registrar minha evolução acadêmica e técnica.

## 📚 Conteúdos estudados

Os exercícios e atividades deste repositório podem abordar:

- Variáveis e tipos de dados.
- Operadores e estruturas condicionais.
- Estruturas de repetição.
- Funções e métodos.
- Funções anônimas e Arrow Functions.
- List, Set e Map.
- Programação Orientada a Objetos (POO).
- Classes, objetos, atributos e métodos.
- Construtores, getters e setters.
- Herança e polimorfismo.
- Funções assíncronas (async/await).
- Callbacks e sobrescrita de métodos (override).
